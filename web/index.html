Cryo-EM metadata screening

Run reproducible, illustrative threshold checks on manually entered numerical metadata. Results are available locally in the browser or from the optional Python API.

Scientific scope: This tool does not read cryo-EM density maps, calculate Fourier shell correlation (FSC), estimate local resolution, assess atomic clashes, or establish wwPDB/EMDB compliance. The values 25 and 12 are example rule thresholds, not validated cryo-EM acceptance criteria. Do not use these outputs for scientific or clinical decisions.
